# TimeSheet Project Management

A project management application with a Timesheet module.

## Features
- **User Panel**: Submit timesheets, view status, delete entries.
- **Admin Panel**: Review timesheets (Approve/Reject), dashboard filtering.
- **Authentication**: Admin login protection.

## Tech Stack
- Frontend: React (Vite)
- Backend: Node.js (Express)
- Database: MongoDB (Mocked/In-memory for demo)

## Setup
1. `cd server` && `npm install` && `node server.js`
2. `cd client` && `npm install` && `npm run dev`
