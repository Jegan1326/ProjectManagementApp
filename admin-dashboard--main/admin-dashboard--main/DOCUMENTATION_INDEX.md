## 📞 Quick Troubleshooting

**Port already in use?**
- Vite auto-selects next available port

**Module not found?**
- Run: `npm install`

**Data not saving?**
- Demo uses localStorage (not database)

**Can't login?**
- Use demo accounts from COMPLETION.md

**Animations not working?**
- Check browser console for errors
